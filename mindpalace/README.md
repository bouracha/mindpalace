# MindPalace

> Last updated: 2026-01-19

**Anthony Bourached's** knowledge operating system. Talk naturally — I organize as patterns emerge.

## How It Works

Everything lives in folders with READMEs. I create structure from our conversations.

- **You talk** → I listen and engage
- **Patterns emerge** → I create folders (people, projects, topics)
- **Updates run** → I summarize sessions and update READMEs
- **You return** → I reconstruct context from timestamps

No setup required. Just start talking.
