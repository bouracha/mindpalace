# Evolution Crystals (palace)

> Last updated: 2026-11-26

An example: why the palace itself changed, its structure, conventions and mechanisms. Keep it, rename it or delete it. Any area can have its own folder like this, in this format or another.

- [changelog.md](changelog.md): one line per change, the chronological spine.
- Dated files (`YYYY-MM-DD-<slug>.md`): full crystals, for changes where the thinking itself moved.

Not loaded by default. Read when someone asks why things are the way they are. The method is described in `docs/evolution-crystals.md` in the MindPalace repository.
