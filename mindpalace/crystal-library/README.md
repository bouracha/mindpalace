# Crystal Library

> Last updated: 2026-11-26

Portable lessons, one claim per file. A crystal's title is its claim; the file says why it matters and where it applies. The method is described in `docs/crystallisation.md` in the MindPalace repository.

The three crystals below are examples: lessons from the author's own palace, there to show the format. Keep, change or delete them, and change the format if another suits you better.

**The format used here:** title (the claim) · type (WHAT, WHY or HOW) · originator tag (`[A]` the author, `[J]` the agent and unvetted, `[J→A]` adopted, `[A+J]` joint, `[J?]` raised and unanswered) · the crystal · why it matters · where it applies.

**A test before adding one:** is it portable, new and stated as a claim? A new instance of an existing crystal can extend that crystal. One row per crystal keeps the index cheap to read.
