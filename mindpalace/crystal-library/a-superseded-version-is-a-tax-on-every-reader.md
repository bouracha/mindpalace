# A superseded version is a tax on every reader

> Type: WHAT / HOW · Originator: `[A]` · Created: 2026-11-26

## The crystal

Every old version kept beside the current one charges each later reader, human or model, the cost of working out which copy is live, and some readers will get it wrong. Keep only the latest version in the working folder. Record the history as reasons, in an evolution crystal, and move old copies out of the working tree if they must be kept at all.

## Why it matters

- A model that navigates by reading cannot tell `plan-v3-final.md` from `plan-v4.md` without opening both, and may quote the wrong one with confidence.
- The cost is paid on every read, for as long as the copy stays. The benefit of keeping it is paid once, if ever.
- Versions answer "what did it say?", which is rarely the question. Reasons answer "why does it say this?", which usually is.

## Where it applies

Document folders, drafts, configuration, slide decks: anything that a model or a colleague will later find by name.
